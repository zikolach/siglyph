# `pi-tui` compatibility matrix

This matrix compares Siglyph with `earendil-works/pi` commit
[`da840b6216578c2a571d0374ac6a2091a83f9d91`](https://github.com/earendil-works/pi/tree/da840b6216578c2a571d0374ac6a2091a83f9d91/packages/tui), reviewed on 2026-09-05. It does not claim drop-in API compatibility or parity with another upstream revision. Siglyph uses Scala-idiomatic typed APIs on JVM and Scala Native.

Status meanings:

- **Full**: The reviewed behavior is present for the documented Siglyph platform scope.
- **Partial**: The main behavior is present with a named gap.
- **Deviation**: Siglyph deliberately uses a different contract.
- **Extension**: Siglyph behavior has no direct counterpart in the reviewed upstream tree.

## Pinned fullscreen comparison

| Area | Status | Pinned upstream behavior | Siglyph behavior and local evidence |
| --- | --- | --- | --- |

[`layout.ts`](https://github.com/earendil-works/pi/blob/da840b6216578c2a571d0374ac6a2091a83f9d91/packages/tui/src/layout.ts) and stack components allocate constrained rows and columns. | `TUI.fullscreen`, `VStack`, and `HStack` provide fixed-height layout while `Component.render(width)` remains valid. | `ScrollView` | Partial | [`scroll-view.ts`](https://github.com/earendil-works/pi/blob/da840b6216578c2a571d0374ac6a2091a83f9d91/packages/tui/src/components/scroll-view.ts) provides one-child vertical scrolling, follow-end, overscroll, and hidden, automatic, or always-visible scrollbars. Automatic scrollbars use a Node timer to hide after activity. | `ScrollView` provides bounded offsets, follow-end, nested chain or contain routing, proportional scrollbars, prompt navigation, and a jump-to-end indicator. Automatic mode stays visible while content overflows and has no timer-based hide delay. See [`FullscreenViewportSuite`](../core/test/src/scalatui/core/FullscreenViewportSuite.scala) and [`ViewportAffordanceSuite`](../core/test/src/scalatui/core/ViewportAffordanceSuite.scala). |
| `MouseRegion` and gestures | Full | [`mouse-region.ts`](https://github.com/earendil-works/pi/blob/da840b6216578c2a571d0374ac6a2091a83f9d91/packages/tui/src/components/mouse-region.ts) wraps child output and receives pointer input. Fullscreen derives click, multi-click, drag, wheel, and selection gestures. | `MouseRegion` preserves typed output and retained layout. The runtime derives semantic move, press, release, click, multi-click, drag, and wheel events with typed capture and focus intents. See [`MouseFoundationSuite`](../core/test/src/scalatui/core/MouseFoundationSuite.scala) and [`TerminalInputParserSuite`](../core/test/src/scalatui/terminal/TerminalInputParserSuite.scala). |
| Fullscreen search | Full | [`alt-screen-search.ts`](https://github.com/earendil-works/pi/blob/da840b6216578c2a571d0374ac6a2091a83f9d91/packages/tui/src/alt-screen-search.ts) indexes normalized rendered text and tracks visible matches. | Primary `ScrollView` search captures input, normalizes Unicode, caches by content revision and width, reveals matches, and highlights visible matches only. See [`TranscriptSearchSuite`](../core/test/src/scalatui/core/TranscriptSearchSuite.scala). |
| Fullscreen selection and copy | Partial | [`tui-alt-screen.ts`](https://github.com/earendil-works/pi/blob/da840b6216578c2a571d0374ac6a2091a83f9d91/packages/tui/src/tui-alt-screen.ts) supports drag, word, and line selection, timer-driven edge scrolling, optional host copy, and OSC 52 fallback. | Selection uses bounded normalized grapheme offsets, event-driven bounded edge scrolling, double-click word selection, and triple-click line selection. Copy is explicit and host-only. There is no automatic copy and no OSC 52 fallback. See [`ViewportSelectionSuite`](../core/test/src/scalatui/core/ViewportSelectionSuite.scala). |
| Viewport image clipping and retention | Deviation | [`layout.ts`](https://github.com/earendil-works/pi/blob/da840b6216578c2a571d0374ac6a2091a83f9d91/packages/tui/src/layout.ts) recognizes image strings and crops partially visible Kitty image rows. Fullscreen retains uploaded Kitty data. | Siglyph clips typed image footprints before encoding. Fully clipped controls are absent. Partial Kitty and iTerm2 controls are omitted because cell geometry cannot validate source-pixel cropping. Per-TUI Kitty retention is count-bounded and generation-bounded. See [`FullscreenViewportSuite`](../core/test/src/scalatui/core/FullscreenViewportSuite.scala) and [`ImageSuite`](../image/test/src/scalatui/image/ImageSuite.scala). |
| Terminal worker failure lifecycle | Extension | The reviewed `Terminal.start` callback surface in [`tui.ts`](https://github.com/earendil-works/pi/blob/da840b6216578c2a571d0374ac6a2091a83f9d91/packages/tui/src/tui.ts) does not define Siglyph's per-worker failure callback and generation contract. | `Terminal.start` has a source-compatible failure callback overload. Built-in reader, fragment-flush, and resize workers report unexpected active-generation failures. `TUI.run` wakes, restores state, and rethrows the first failure with later failures suppressed. See [`TUITerminalFailureSuite`](../core/test/src/scalatui/core/TUITerminalFailureSuite.scala), [`StreamTerminalSuite`](../core/test/src/scalatui/terminal/StreamTerminalSuite.scala), [`SttyTerminalSuite`](../terminalJvm/test/src/scalatui/terminal/jvm/SttyTerminalSuite.scala), and [`PosixTerminalSuite`](../terminalNative/test/src/scalatui/terminal/native/PosixTerminalSuite.scala). |

## Broader API and behavior coverage

| Area | Status | Siglyph scope and evidence |
| --- | --- | --- |
| Component and runtime foundation | Deviation | `ComponentRender`, `TerminalInput`, cursor placements, and terminal controls are typed rather than TypeScript-compatible. Runtime and render contracts are covered by [`TUISuite`](../core/test/src/scalatui/core/TUISuite.scala) and [`ComponentRenderSuite`](../core/test/src/scalatui/core/ComponentRenderSuite.scala). |
| Basic components | Full | `Text`, `Box`, `Spacer`, `TruncatedText`, and `Input` cover the reviewed high-level behavior. See [`ComponentsSuite`](../core/test/src/scalatui/components/ComponentsSuite.scala) and [`UtilityComponentsSuite`](../core/test/src/scalatui/components/UtilityComponentsSuite.scala). |
| Editor, selectors, settings, and loaders | Partial | Editor, `SelectList`, `SettingsList`, `Loader`, and `CancellableLoader` are present. Loader ticking is application-owned instead of Node timer-owned. See [`EditorSuite`](../core/test/src/scalatui/components/EditorSuite.scala), [`SelectListSuite`](../core/test/src/scalatui/components/SelectListSuite.scala), and [`LoaderConcurrencySuite`](../core/test/src/scalatui/components/LoaderConcurrencySuite.scala). |
| Autocomplete and fuzzy matching | Partial | Callback and cancellation APIs replace promises and `AbortSignal`. Bounded NIO discovery replaces process-based filesystem search. See [`AutocompleteSuite`](../core/test/src/scalatui/autocomplete/AutocompleteSuite.scala) and [`FileSystemPathCompletionProviderSuite`](../core/test/src/scalatui/autocomplete/FileSystemPathCompletionProviderSuite.scala). |
| Markdown | Partial | The dependency-free baseline is smaller than `marked` and full CommonMark. Parser adapters remain pluggable. See [`MarkdownRendererSuite`](../markdown/test/src/scalatui/markdown/MarkdownRendererSuite.scala) and [`markdown-parser-research.md`](markdown-parser-research.md). |
| Terminal images outside fullscreen | Deviation | Typed payloads and controls replace upstream string-prefix authority. Image decoding, scaling, and transcoding are not built into core. See [`TerminalImageProtocolSuite`](../core/test/src/scalatui/terminal/TerminalImageProtocolSuite.scala) and [`ImageSuite`](../image/test/src/scalatui/image/ImageSuite.scala). |
| Keyboard input | Partial | Common CSI, SS3, function, keypad, control, and Kitty forms are typed. Unknown or ambiguous encodings remain bounded raw input. See [`TerminalInputParserSuite`](../core/test/src/scalatui/terminal/TerminalInputParserSuite.scala) and [`keybinding-defaults.md`](keybinding-defaults.md). |
| Terminal backends | Partial | JVM `stty` and Scala Native POSIX backends target macOS and Linux. Windows is excluded. Emulator-specific visual parity is not claimed. See [`terminal-conformance.md`](terminal-conformance.md). |
